# Contributing

Issues and pull requests are welcome. Keep changes small and focused.

- Python 3.9 or later, standard library only. Do not add runtime dependencies.
- Run the suite before you send a change: `python -W error -m unittest discover -s tests -v`
- Add a test with every behaviour change or bug fix, and a line in `CHANGELOG.md`.
- Security reports go through private vulnerability reporting, see `SECURITY.md`.

By contributing you agree that your work is released under the Apache-2.0 license.
